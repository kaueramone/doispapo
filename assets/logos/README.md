- Roxo (fim do gradiente): `#8C41D9` · rgb(140, 65, 217)
- Gradiente aplicado na horizontal, esquerda → direita.

## Observações para uso no Stoat
- O logotipo é **horizontal-ish com texto embaixo** (proporção ~1.30:1).
  Para avatar de servidor ou favicon, que são quadrados e pequenos, o texto
  fica ilegível — precisa de um recorte só do símbolo (o balão com fones).
- Não existe SVG. Para escalar acima de 1736 px de largura sem perda, seria
  preciso o arquivo vetorial original.
